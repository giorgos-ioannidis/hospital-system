# Screenshots ανά οθόνη (2ο Παραδοτέο)

Κάθε εικόνα έχει το όνομα της οθόνης UI-xx (ίδιο με το template), ώστε να αντιστοιχεί ένα προς ένα σε ΠΧ και FR
(πλήρης αντιστοίχιση: [`../traceability.md`](../traceability.md)). Οι φάκελοι: `*.png` σε υπολογιστή (1440 px),
`mobile/*.png` σε κινητό (390 px), ως απόδειξη του NFR-05.

## Πώς ξαναβγαίνουν
1. Ξεκινήστε **φρέσκια** εφαρμογή στο dev: `./mvnw spring-boot:run` (η H2 ξαναγεμίζει με τα demo δεδομένα).
2. Σε άλλο τερματικό: `node docs/screenshots/capture.mjs` (Node ≥ 22 και Google Chrome).
   Σε Windows/Linux: `CHROME_PATH="<διαδρομή του chrome>" node docs/screenshots/capture.mjs`.

Το script συνδέεται ως κάθε ρόλος και παίζει τις ροές: παραγωγή και έγκριση προγράμματος, αίτηση άδειας, κράτηση με
πληρωμή, απόπειρα πρόσβασης σε ξένο φάκελο. Έτσι κάθε οθόνη έχει δεδομένα.
