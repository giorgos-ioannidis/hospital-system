# Σενάριο tutorial video (2ο Παραδοτέο)

**Διάρκεια:** ~10 λεπτά · **Ανάλυση:** 1920×1080, browser σε 100% zoom · **Αφήγηση:** ελληνικά, ένα μέλος ανά ενότητα.

## Προετοιμασία (πριν πατήσετε εγγραφή)
1. Φρέσκια εκκίνηση: `./mvnw spring-boot:run` (η H2 ξαναγεμίζει με τα demo δεδομένα).
2. Chrome σε παράθυρο ανώνυμης περιήγησης, μόνο μία καρτέλα, χωρίς σελιδοδείκτες.
3. Δεύτερη καρτέλα έτοιμη για αλλαγή χρήστη: αποσύνδεση και σύνδεση με τον επόμενο ρόλο (κωδικός `demo1234`).
4. IntelliJ ανοιχτό στο `GreedyScheduleGenerator`, με το παράθυρο των tests έτοιμο.
5. Εγγραφή οθόνης: QuickTime (macOS) ή OBS. Ήχος από μικρόφωνο, όχι από το laptop.
